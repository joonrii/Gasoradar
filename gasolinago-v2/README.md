# GasolinaGo V2

Nueva arquitectura del producto GasolinaGo.

## Objetivo

Construir una plataforma nacional de precios de carburantes con tres pilares:

- SEO local basado en datos reales.
- Producto para decidir dónde repostar.
- Datos e históricos actualizados automáticamente.

## Arquitectura prevista

- `datos/estaciones.json`: catálogo nacional y precios actuales.
- `datos/historico.json`: histórico agregado.
- páginas locales generadas desde datos.
- futura función de mejor opción según precio, distancia y ruta.

Esta carpeta es una especificación inicial y no sustituye todavía la aplicación actual.
